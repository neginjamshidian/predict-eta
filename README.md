# predict-eta (notebook-to-python export)

This repo was generated by converting `FinalTransitTest.html` (a Jupyter HTML export) into a Python CLI-style project.

## Files
- `main.py` — concatenated Python code cells with safety guards (secret scrubbing + mock data helpers).
- `data_utils.py` — utilities to create small mock datasets if your code expects local files.
- `requirements.txt` — best-effort dependency list inferred from imports.
- `.gitignore` — Python ignores.

## Run
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Mock data
If your code needs local files (e.g., `data/train.csv`) and they aren't present, call:
```python
from data_utils import get_or_make_mock_csv
csv_path = get_or_make_mock_csv("data/train.csv", columns=("feature1","feature2","target"))
```

## Safety
- Hardcoded secrets are **redacted** and a runtime scrubber warns if any slip through.
- Avoid committing private data. Keep real keys in environment variables (e.g. `.env` but don't commit it).

Replace `<YOUR_GITHUB_USERNAME>` and ensure you have write access to your `predict-eta` repo.

```bash

git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/predict-eta.git
```
